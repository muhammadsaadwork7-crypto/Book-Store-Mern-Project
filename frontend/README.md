# 📚 Online Book Store (MERN Stack)

## 📌 Overview
The **Online Book Store** is a full-stack web application built using the MERN stack (MongoDB, Express.js, React.js, Node.js). It supports both **customers** and **administrators**, providing an efficient platform to manage and purchase books online.

## 🚀 Features

### 👤 Customer Side
- User **Sign Up & Login**
- View **recently added books** on landing page
- Browse **all available books**
- Add books to **cart**
- View and manage **cart items**
- Access and manage **user profile**

### 🛠️ Admin Side
- Secure **admin login**
- **Add new books**
- **Delete books**
- View **order history**
- **Track orders**

## 🏗️ Tech Stack

### Frontend
- React.js
- CSS / Bootstrap / Tailwind

### Backend
- Node.js
- Express.js

### Database
- MongoDB (Mongoose)

## ⚙️ Installation & Setup

### 1. Install Dependencies

#### Backend
```bash
cd server
npm install
```

#### Frontend
```bash
cd frontend
npm install
```


### 3. Run the Project

#### Start Backend
```bash
npm start
```

#### Start Frontend
```bash
npm start
```
